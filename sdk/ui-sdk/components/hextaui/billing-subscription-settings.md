Manage subscription settings including pause, cancel, and billing period.

## Dependencies

- Frozen base (consumer):
  `@/lib/utils`, `@/components/ui/alert-dialog`, `@/components/ui/badge`, `@/components/ui/button`
  `@/components/ui/card`, `@/components/ui/select`, `@/components/ui/separator`
  `@/components/ui/switch`
- npm: `lucide-react`

## Usage

```tsx
import { BillingSubscriptionSettings } from "@/components/hextaui/billing-subscription-settings"

<BillingSubscriptionSettings />
```
