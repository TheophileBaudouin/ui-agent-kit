# follow-up-suggestions

Suggestion chips rendered under the last assistant message (from the `suggestions` thread
data), letting the user continue the conversation with one click.

## Dependencies

- npm: `@assistant-ui/react`, `react`

## Usage

```tsx
import { ThreadFollowupSuggestions } from "@/components/assistant-ui/follow-up-suggestions"
```

> Rendered automatically by `thread.tsx`.
