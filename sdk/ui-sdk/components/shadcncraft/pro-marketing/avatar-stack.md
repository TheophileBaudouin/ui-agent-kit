A compact component for displaying multiple stacked user avatars.

## Dependencies

- Frozen base (consumer): `@/lib/utils`
- npm: none

## Usage

```tsx
import { AvatarStack } from "@/components/shadcncraft/avatar-stack"

<AvatarStack />
```
