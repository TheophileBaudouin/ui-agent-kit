Composed chart component rendered with Apache ECharts.

## Dependencies

- Frozen base (consumer):
  `@/components/evilcharts/ui/echarts-tooltip`, `@/components/evilcharts/ui/echarts-brush`
  `@/components/evilcharts/ui/echarts-chart`, `@/components/evilcharts/ui/echarts-dot`
  `@/components/evilcharts/ui/echarts-legend`
- npm: `echarts/components`, `echarts/charts`, `echarts/core`, `motion/react`, `echarts/renderers`

## Usage

```tsx
import { EChartsComposedChart } from "@/components/evilcharts/echarts-composed-chart"

<EChartsComposedChart />
```
