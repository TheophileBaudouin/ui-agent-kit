Pie chart component rendered with Apache ECharts.

## Dependencies

- Frozen base (consumer):
  `@/components/evilcharts/ui/echarts-tooltip`, `@/components/evilcharts/ui/echarts-chart`
  `@/components/evilcharts/ui/echarts-legend`
- npm: `echarts/components`, `echarts/charts`, `motion/react`, `echarts/renderers`, `echarts/core`

## Usage

```tsx
import { EChartsPieChart } from "@/components/evilcharts/echarts-pie-chart"

<EChartsPieChart />
```
