Line chart component rendered with Apache ECharts.

## Dependencies

- Frozen base (consumer):
  `@/components/evilcharts/ui/echarts-tooltip`, `@/components/evilcharts/ui/echarts-brush`
  `@/components/evilcharts/ui/echarts-chart`, `@/components/evilcharts/ui/echarts-dot`
  `@/components/evilcharts/ui/echarts-legend`
- npm: `echarts/components`, `echarts/charts`, `motion/react`, `echarts/renderers`, `echarts/core`

## Usage

```tsx
import { EChartsLineChart } from "@/components/evilcharts/echarts-line-chart"

<EChartsLineChart />
```
