Bar chart component rendered with Apache ECharts.

## Dependencies

- Frozen base (consumer):
  `@/components/evilcharts/ui/echarts-tooltip`, `@/components/evilcharts/ui/echarts-brush`
  `@/components/evilcharts/ui/echarts-chart`, `@/components/evilcharts/ui/echarts-legend`
  `@/components/evilcharts/ui/echarts-dot`
- npm: `echarts/components`, `echarts/core`, `echarts/charts`, `motion/react`, `echarts/renderers`

## Usage

```tsx
import { EChartsBarChart } from "@/components/evilcharts/echarts-bar-chart"

<EChartsBarChart />
```
