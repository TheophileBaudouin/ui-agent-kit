Tooltip helper for Recharts charts.

## Dependencies

- Frozen base (consumer): `@/components/evilcharts/ui/recharts-chart`, `@/lib/utils`
- npm: `recharts/types/component/DefaultTooltipContent`, `recharts`

## Usage

```tsx
import { recharts-tooltip } from "@/components/evilcharts/recharts-tooltip"

<recharts-tooltip />
```
