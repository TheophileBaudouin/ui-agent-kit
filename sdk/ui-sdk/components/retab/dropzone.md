A headless file-intake primitive with drag/drop and file input wiring.

## Dependencies

- Frozen base (consumer): none
- npm: `@radix-ui/react-slot`

## Usage

```tsx
import { DropzoneProvider } from "@/components/retab/dropzone"

<DropzoneProvider />
```
