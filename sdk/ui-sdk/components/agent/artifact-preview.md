Preview card for an artifact generated by the agent (file, report, diff…): type icon +
title + meta header, content slot, and optional Copy / Open / Download actions (each
button only renders when its callback is provided). Presentational.

## Dependencies

- Frozen base (consumer): `@/components/ui/button`, `@/lib/utils`
- npm: `lucide-react`

## Usage

```tsx
import { ArtifactPreview } from "@/components/agent/artifact-preview"

<ArtifactPreview
  title="release-notes.md"
  meta="Markdown · 2 KB"
  onCopy={() => navigator.clipboard.writeText(md)}
  onOpen={openInApp}
>
  <pre className="text-xs">{md.slice(0, 200)}…</pre>
</ArtifactPreview>
```

> In a Thread, pass this as the `children` of a `ToolResult` for tools that generate
> files — or render it directly for external agent runtimes.
